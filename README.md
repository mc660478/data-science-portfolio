# Data Science Portfolio

This repository contains the source files for my portfolio website, published with GitHub Pages.

## Website content
- `index.md`: portfolio home page
- `figures/property_price_index_trend.png`: project visualization displayed on the page

## Publishing
In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then save. Open the URL shown in the Pages settings after publication.

## Before publishing
- Replace `YOUR-GITHUB-USERNAME` in `index.md` with your GitHub username.
- Add your real name if required by your course.
- Check the project link and image after the website is published.
- Review all public content for personal or sensitive information.
